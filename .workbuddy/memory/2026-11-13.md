## PluginMedia：部分格式拖动进度条无效（根因 + 修复 + Qt6 迁移）

### 根因（FFmpeg 8.1 探针实测，非推测）
`Plugins/PluginMedia/mainwindow.cpp::showVideo` 用
`avio_alloc_context(m_avioBuffer, nFileLen, 0, nullptr, nullptr, nullptr, nullptr)`
把整个文件当作 AVIO 内部 buffer，read/seek 回调全为 NULL：
- `pb->seekable == 0`，`avio_size()` 返回 -40 (ENOSYS)；
- FLV / MPEG-TS：`av_seek_frame(..., AVSEEK_FLAG_BACKWARD)` 返回 -1 `Operation not permitted`；
- AVI：seek 返回 0 但 IO 位置跳回 9996（文件头），首包 PTS=0，属静默失败；
- MP3 / TS：拿不到文件长度 → `duration = AV_NOPTS_VALUE` → 代码回退成 60000ms 假时长；
- MP4 / MOV / MKV / WebM / ASF：整个文件在同一块 buffer 内，FFmpeg 走 buffer 内 seek
  快速路径，表现正常 —— 这就是「只有部分格式不能拖动」的原因。
探针 `.workbuddy/tmp/seek_probe/seek_probe.c`（mode 0 = 旧实现 / mode 1 = 有回调），
日志 `run.log`、`run2.log`；9 个容器测试片由 `D:\ffmpeg` 生成。

### 追加修复：mp3float "Could not update timestamps for skipped/discarded samples"
用户贴出播放 mp3 时的两条 libavcodec 警告（skipped + discarded samples）。
- **根因**：`showVideo` 只用 `avcodec_parameters_to_context()` 填解码器上下文，
  从未设置 `AVCodecContext::pkt_timebase`（默认 0/1）。`libavcodec/decode.c` 在
  处理 `AV_PKT_DATA_SKIP_SAMPLES` 的 skip_samples / discard_padding（MP3 LAME/Xing、
  AAC priming、Opus pre-skip 等 gapless 信息）时，需要
  `av_rescale_q(samples, {1, sample_rate}, pkt_timebase)` 把跳过的样本时长加到
  `frame->pts / pkt_dts / duration` 上；`pkt_timebase.num == 0` 时只能打这两条
  `AV_LOG_WARNING` 并**放弃时间戳修正**，音频帧 PTS 偏早约一个 encoder delay
  （mp3 skip_samples=1105 @44100 ≈ 25ms）。不是解码失败，音频样本仍正确跳过。
  两条警告是同一个判断的两个 else 分支，修复点相同。
- **修复**：`Plugins/PluginMedia/mainwindow.cpp` 在 `avcodec_open2` 之前补两行
  `pCodecCtx->pkt_timebase = vstream->time_base;`
  `aCodecCtx->pkt_timebase = astream->time_base;`（+11 行，含注释）。
  注意 `m_nStartMs`（容器 start_time）与这里的解码器 skip 修正不冲突：
  frame pts 前进 25ms 后再减容器 25ms 偏移，起点仍为 0。
- **A/B 实证**：`.workbuddy/tmp/seek_probe/ts_probe.c`（MinGW gcc 编译，
  `ts_probe.exe <file> <0|1>`）对带 discard_padding 的样本开关 pkt_timebase：
  `test_pad.mp3`（skip=1105, padding=461）tb=0 → 2 条警告、tb=1 → 0 条；
  `test.ogg`（skip=312, padding=648）tb=0 → 2 条、tb=1 → 0 条，
  两次解码帧数一致（143 / 186），证明只影响时间戳修正、不影响解码。
- **回归**：Qt6 插件/集成测试/顶层全项目三处重建均 EXIT=0 且 0 error；
  9 容器拖动测试 `.workbuddy/tmp/qt6_itest/run_pkt_tb.log` 警告数 0，
  进度条 AFTER 值与修复前一致（6160~6766ms，TS 仍 5000 属样本关键帧边界）；
  新增 gapless 样本（test_pad.mp3 / test.m4a / test.ogg）实例测试
  `run_gapless.log` 警告数 0。
